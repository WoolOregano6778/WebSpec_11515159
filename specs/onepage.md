# 根付之源｜雷之印兌換頁網頁規格

> 本文件依據 `WebPage_11515159/outline/index.html` 現有內容整理，描述目前頁面的資訊、視覺與互動，作為後續修改網頁的依據。商品名稱、敘述與印記數量依現有畫面記錄；若要呈現正式遊戲資料，請另行核對與更新。

## 1. 網站基本資料

- **網站名稱：** 根付之源
- **頁面標題：** 根付之源｜雷之印兌換
- **頁面用途：** 介紹稻妻根付之源可兌換的珍藏，讓旅行者查看商品、雷之印需求與開放條件。
- **目標受眾：** 《原神》旅行者、稻妻居民，以及對稻妻商品兌換資訊有興趣的訪客。
- **語言：** 繁體中文（`zh-Hant`），搭配少量英文裝飾文字。
- **頁面型態：** 單頁式介紹與商品目錄頁；導覽以頁內錨點移動。
- **目標路徑：** `WebPage_11515159/outline/index.html`

## 2. 品牌與視覺方向

- **品牌印象：** 稻妻、雷電、神櫻、珍藏、奇幻、典雅。
- **主色調：** 深夜紫與紫羅蘭色，搭配淡紫、粉紫及少量金色。
- **背景：** 全站深色背景；主視覺以深紫漸層和柔和紫色光暈營造層次，商品區使用另一階深紫底色。
- **文字：** 淡色文字作主要資訊；灰紫色作次要說明；淡金色凸顯貨幣與門檻。
- **裝飾語彙：** 圓形印記、同心圓、虛線環、光暈、細邊框及雷字標誌。
- **字型：** 優先使用 `Noto Sans TC`、`Microsoft JhengHei`，最後退回系統無襯線字體。
- **版面寬度：** 主要內容最大寬度約 1120px，桌機置中；左右留白隨螢幕縮放。
- **圖片與外部資源：** 現有頁面不依賴外部圖片或 JavaScript 套件。主視覺以 CSS 圓形與文字「雷」製作；商品圖片以表情符號作為圖示。

### 3.4 兌換方式與解鎖條件（`#guide`）

- 淺一階的深紫背景，桌機左右雙欄，窄螢幕改為上下排列。
- 左欄標題：「開啟珍藏／從供奉神櫻開始」。
- 說明指出提升神櫻眷顧等級可解鎖更多兌換珍藏。
- 解鎖資訊卡以金色突出「50」，附「神櫻眷顧／解鎖等級」標籤。
- 資訊卡說明：供奉神櫻樹達到 50 等之後，便可在根付之源兌換商品，並提醒準備足夠雷之印。
- 右欄為三步驟清單：
  1. **收集雷之印：** 探索稻妻島嶼與寶箱，累積雷之印。
  2. **供奉神櫻樹：** 前往鳴神大社供奉雷之印，提升神櫻眷顧等級。
  3. **達到 50 等後兌換：** 解鎖根付之源兌換功能，挑選珍藏。

## 4. 互動與行為

- 導覽、主視覺按鈕使用頁內錨點平滑捲動到對應區塊。
- 商品卡片的「兌換資訊」按鈕不會進行實際兌換；點擊後顯示頁面右下角狀態提示：
  - `「{商品名稱}」的兌換需神櫻樹供奉達 50 等後開放。`
- 提示使用 `role="status"` 與 `aria-live="polite"`，約 3.2 秒後自動隱藏；再次點擊會重設計時並更新訊息。
- 卡片滑鼠移入時微幅上移並加亮邊框；按鈕移入時改變底色。
- 鍵盤操作連結及按鈕時顯示金色外框焦點樣式。
- 偏好減少動態效果的使用者不會看到平滑捲動及一般過場動畫。
- 不包含購物車、使用者帳號、雷之印餘額、後端兌換或資料儲存功能。

## 5. 響應式規格

- **大螢幕（預設）：** 主要容器最大寬度 1120px；主視覺雙欄；商品卡片三欄；兌換方式雙欄。
- **中型螢幕（寬度 780px 以下）：** 導覽間距縮小；主視覺改為較窄的左右雙欄；徽記縮小；商品卡片兩欄。
- **手機（寬度 560px 以下）：** 外距縮至 17px；主視覺文字在上、徽記在下；商品卡片單欄；商品資訊列直向排列；兌換步驟欄改為單欄；頁尾內容直向排列。
- 內容不可因縮放而溢出視窗；標題使用 `clamp()` 調整字級。

## 6. 無障礙與語意

- 文件語言為繁體中文，包含 viewport 與頁面描述 meta 標籤。
- 導覽使用 `<nav>`，主內容使用 `<main>`，各區使用 `<section>` 與標題關聯（`aria-labelledby`）。
- 商品以 `<article>` 表示；兌換步驟以有序清單 `<ol>` 表示。
- 裝飾圖示採隱藏或替代文字，互動按鈕使用原生 `<button>`。
- 提示訊息使用狀態區域宣告，避免只以顏色傳達資訊。
- 支援 `prefers-reduced-motion`。

## 7. 製作與修改準則

- 維持單一 HTML 檔案，CSS 放在 `<style>`，互動 JavaScript 放在頁尾 `<script>`。
- 不需建置工具或外部圖片即可呈現目前版面。
- 若更新商品，應同步修改商品分類、名稱、介紹、印記需求及按鈕的商品名稱資料。
- 若更新解鎖門檻，應一併修改解鎖卡、流程第三步、頁尾提醒及按鈕點擊提示，避免不同區塊資訊不一致。
- 如需換成正式商品圖片，保留商品圖示區尺寸與替代文字，並確保窄螢幕仍完整顯示。
